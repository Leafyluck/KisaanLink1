❓ Help

Simple explanations for using KisaanLink.

How do I sell?

Choose Sell Crop and enter your crop, quantity, price and location. The full marketplace API can be connected next.

What is Crop Advice?

It uses the Random Forest model in your backend to estimate demand and identify a supply gap.

Need another language?

The UI is intentionally simple so a multilingual layer can be added later without changing the API.
